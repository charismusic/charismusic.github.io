# Charis Music Free Music Note Generator v2.0

GitHub Pages-ready static project.

## New in v2.0
- Clefs: Treble, Bass, Alto, Tenor
- Alto and Tenor use the supplied Finale C-clef glyph; only its vertical position changes.
- Alto range: B2–E5
- Tenor range: G2–E5
- Accidentals: Natural (no sign), Sharp, Flat
- Quarter and Eighth notes retained
- Three spacing presets retained
- Latest optical corrections retained (stem-up horizontal correction and global note vertical correction)

## Calibration sources
The C-clef and accidental glyph geometry was extracted from the supplied Finale SVG files:
- Alto clef.svg
- example alto clef.svg
- example tenor clef.svg
- flat.svg
- Sharp.svg

## Deploy
Upload index.html, style.css and app.js to the same GitHub Pages directory.
